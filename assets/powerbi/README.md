# Power BI screenshots

Chụp ảnh từ Power BI Desktop sau khi đã mở `powerbi/SoccerAnalytics.pbip`, Refresh thành công và kiểm tra bộ lọc. Thư mục này chưa có ảnh chụp Power BI thực tế.

Tên tệp đề xuất:

- `01_overview.png`: trang Tổng quan, bỏ mọi bộ lọc.
- `02_team_performance.png`: Premier League, mùa 2015/2016.
- `03_home_away.png`: so sánh sân nhà và sân khách.
- `04_season_changes.png`: Premier League, mùa sau 2015/2016.
- `05_quality_checks.png`: bảng kiểm tra và lưu ý phạm vi.

Sau khi có ảnh thật, thêm ảnh phù hợp vào README ở thư mục gốc, ví dụ:

```markdown
![Power BI overview](assets/powerbi/01_overview.png)
```

Các ảnh hiện có ở thư mục `assets/` cấp trên là biểu đồ thống kê đã tạo từ kết quả SQL, không phải ảnh Power BI.
